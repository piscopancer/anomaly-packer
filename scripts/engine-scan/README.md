# engine-scan

Скрипты для сверки рукописных движковых типов (`src/types/game/__base.d.ts` и
`src/types/game/__base/*.d.ts`) с исходниками X-Ray Monolith. Типы — это
luabind-биндинги движка, вывести их из папки `scripts` нельзя, поэтому источник
истины — C++-регистрации `luabind::class_<...>.def("name", &...)`.

## luabind_scan.py

Обходит все `*.cpp` в указанном репозитории движка и вытаскивает авторитетный
реестр регистраций: имя luabind-класса, C++-тип, базовый класс, конструкторы
(с типами аргументов), методы (`.def`), поля (`.def_readwrite` / `.def_readonly`),
свойства (`.property`, с признаком read/write) и члены энумов (символьное
выражение значения).

```
python luabind_scan.py <путь-к-репо>/src > vanilla_api.json
```

Типы аргументов методов в `.cpp` физически отсутствуют — они в заголовках.
Скрипт даёт состав API (какие методы/поля/классы вообще есть); типы аргументов
досматриваются точечно в заголовках только по расхождениям.

## enum_resolve.py

Резолвит числовые значения энумераторов из заголовков (`.def` в `.cpp` содержит
лишь символы вроде `eHitTypeBurn`).

```
python enum_resolve.py <путь-к-репо>/src eHitTypeBurn sm_Looped ...
```

## Два клона движка

- Ваниль (сток Anomaly 1.5.3): bitbucket anomalymod
- Модовый (modded exes, форк demonized): github themrdemonized

Что есть в ванили → `__base.d.ts`; что форк добавил сверху → `modded_exes.d.ts`
через слияние интерфейсов. Дельту даёт set-diff имён между прогонами по двум
репозиториям.
