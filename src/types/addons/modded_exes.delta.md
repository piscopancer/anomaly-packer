# Modded exes — полная дельта скриптового API (достоверная, repo-wide)

## СТАТУС (проход по дельте выполнен, tsc --noEmit зелёный)

Покрыто в типах (слияние интерфейсов в `modded_exes.d.ts`, ванильные части новых
движковых классов — в `game/__base/engine-classes.d.ts` и `__base/math.d.ts`):

- `CGameObject` — все fork-методы: hud fire points/bones, get_actor_* looking/luminosity,
  anomaly/restrictor, casts (cast_Knife/Missile/Explosive), shaders, script attachments,
  bone_transform/xform/bounding_box, smart cover, devices, set_movement/vision_speed.
- `CWeapon` — 81 метод: cam/zoom dispersion, PDM-отдача (base/vel/accel/crouch по
  attachment'ам), crosshair inertion, fire points, m_Offset/strap, RealRPM, misfire.
- `matrix` (ваниль в __base + fork-методы: build_camera_dir/projection, mul*_43/44,
  translate/transform/invert/scale, hud_to_world/world_to_hud), `vector4` (целиком fork),
  `vector` (hud_to_world[_dir]/world_to_hud[_dir]).
- Новые движковые классы (ваниль в __base + fork-дельта): `CCar`, `holder`, `CExplosive`,
  `physics_shell`, `physics_element`, `render_device` (+`device()`), `particles_object`,
  `CConsole` (+`get_console()`). Целиком fork: `CMissile`, `CWeaponKnife`, `CWeaponStatMgun`,
  `CProjector` (searchlight), `ScriptAttachment` (46), `CWeaponSSRS` (пустой).
- UI: `CUIStatic`, `CUIMainIngameWnd`, `CUIProgressBar`, `CUIPropertiesBox`, `CUIPdaWnd`,
  `CUIListBoxItem`, `CUIDialogWnd`.
- `alife`: force_update, object_ids, iterate_objects, iterate_level_objects_of_clsid, max_id.
- `cse_alife_level_changer`: dest_game_vertex_id/dest_level_vertex_id/dest_position (readonly).
- `ray_pick.get_normal`; debug-render: `DBG_ScriptObject`/`Sphere`/`Box`/`Line` + namespace
  `debug_render` (add_object/get_object/remove_object/get_flags/set_flags).

Отдельные подсистемы (НЕ входят в 320 gameplay-имён):
- `ImGui` — типизирован целиком в `modded_exes/imgui.d.ts`: namespace `ImGui` (модуль
  зарегистрирован как `ImGui`, не `imgui`) со всеми функциями из `script_imgui_script.cpp`
  плюс `const enum`-ы флагов/ключей с реальными значениями из `imgui.h`. Класс `fcolor`
  (ванильный) вынесен в `game/__base/math.d.ts`. Источник сигнатур — сам биндинг,
  инлайн-обёртки `script_imgui_inline.h` и рукописный референс `lua_help_imgui.script`.
- Скриптинг шейдеров (вне прохода): `_compiler` (+`dx10cullmode`), `_dx10options` (+`getLevel`), `blend`,
  `_sampler` из `ResourceManager_Scripting.cpp` — API для `shaders/*.s`, не геймплейный.

Мусор в старом чеклисте (реально НЕ зарегистрированы — закомментированы в
`alife_simulator_script.cpp`): `objects_iter`, `objects_without_actor_iter`,
`iterate_objects_without_actor` и классы-итераторы `alife_object_iterator` — пропущены.
